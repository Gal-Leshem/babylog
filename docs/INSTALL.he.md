# מדריך התקנה (לבעל החשבון)

כתובות וקודים אישיים לא נכתבים כאן. אותם מקבלים במהלך ההתקנה.

## 1. פעם אחת: הפעלת GitHub Pages
אם האתר לא נפתח: במאגר ב-GitHub, Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **gh-pages**, תיקייה **/ (root)** ← Save.
אחרי דקה האתר חי. אותה כתובת תהיה כתובת האפליקציה.

## 2. אישור השרת (כ-3 דקות, פעם אחת)
1. ב-Google Drive תמצאו שני גיליונות: **BabyLog** (האמיתי) ו-**BabyLog TEST** (לבדיקות אוטומטיות).
2. ב-script.google.com לחצו על הפרויקט **BabyLog** (העורך נפתח מיד; התפריט Extensions קיים רק בתוך הגיליון עצמו).
3. למעלה, בתפריט הפונקציות ליד Run, בחרו **setup** ולחצו **Run**.
4. Google תבקש הרשאה: Review permissions ← בחרו את החשבון ← "Google hasn’t verified this app" ← **Advanced** ← **Go to BabyLog (unsafe)** ← Allow.
   (זה הסקריפט שלכם עצמו, והוא מבקש גישה רק לגיליון הזה.)
5. בחלון ה-Execution log יודפס **קוד התקנה** שמתחיל ב-`BL1.`. העתיקו אותו. זה המפתח הסודי: אל תשלחו אותו בשום מקום ציבורי.
6. אותו דבר ב-**BabyLog TEST** (רק Run על setup ואישור, בלי להעתיק קוד). זה מאפשר לבדיקות האוטומטיות לרוץ.

אם בהדפסה כתוב שהכתובת לא זמינה: Deploy ← Manage deployments, והעתיקו את הכתובת שמסתיימת ב-`/exec`.

## 3. התקנת האפליקציה בכל טלפון
1. פתחו את כתובת האתר ב-**Safari** (חייב Safari).
2. כפתור השיתוף ← **Add to Home Screen**.
3. פתחו את האפליקציה **מהאייקון במסך הבית**, הדביקו את קוד ההתקנה, והגדירו שמות: הורה 1, הורה 2 ושם התינוק (נשמרים בגיליון הפרטי בלבד). בחרו "מי אני".
4. בטלפון השני אותו קוד. השמות כבר ימולאו, רק בוחרים "מי אני".

## 4. קיצורי Siri (ב-Mac, כ-5 דקות)
בטרמינל, עם כתובת האתר במקום `SITE`:

```bash
curl -fsSL "SITE/shortcuts/sign.sh" -o /tmp/babylog-sign.sh
BABYLOG_SITE="SITE" bash /tmp/babylog-sign.sh
```

הסקריפט מבקש להדביק את קוד ההתקנה (לא מוצג בזמן ההדבקה), שואל את השרת מה שמות ההורים, ויוצר על שולחן העבודה תיקייה לכל הורה עם 9 קיצורים חתומים.
שלחו כל תיקייה בהודעה פרטית ל-AirDrop לטלפון של ההורה המתאים, פתחו כל קובץ ולחצו **Add Shortcut**. אחר כך מחקו את התיקייה מה-Mac (יש בה את המפתח).

הביטויים לסירי (באנגלית): Left feed, Right feed, Wet diaper, Poop, Full diaper, Asleep, Awake, Vitamin D, ושאלה: Last feed.

## 5. הפעלה בלי לפתוח את האפליקציה
- **Back Tap**: הגדרות ← נגישות ← מגע ← Back Tap ← הקשה כפולה/משולשת ← בחרו קיצור.
- **כפתור הפעולה** (אצל מי שיש): הגדרות ← Action Button ← Shortcut.
- **מרכז הבקרה / מסך הנעילה**: iOS 18 ומעלה, Edit ← Add a Control ← Shortcuts.

## 6. בדיקת קבלה (כ-15 דקות)
בכל טלפון: לחיצה על כל כפתור (תופיע הודעת "נשמר" עם ביטול), היסטוריה/עריכה/מחיקה, הוספה בדיעבד, מצב טיסה (נרשם, ומסתנכרן אחרי חזרת הקליטה), מצב לילה, "Hey Siri, Left feed" (גם כשהטלפון נעול: **לבדוק אם נדרש Face ID**).
בדקו שהשינוי של הורה אחד מופיע אצל השני תוך דקה.

## 7. שכבת AI (בדיקה)
חברו את Google Drive ל-ChatGPT ול-Gemini ושאלו, למשל:
- כמה פעמים הוא אכל אתמול?
- מה הרווח הממוצע בין ההאכלות הלילה?
- כמה שעות ישן ביממה האחרונה, ומה הרצף הארוך ביותר?
- היו חיתולים עם צואה היום?
- ניתן ויטמין D היום?

אם Gemini לא רואה גיליון ששותף איתכם: הוסיפו את הגיליון ל"ה-Drive שלי" דרך Shortcut.

## אם משהו לא עובד
- **האפליקציה אומרת "המפתח לא תקין"**: Settings ← ניתוק, והתחברו מחדש עם קוד מ-`printInstallCode` (בעורך הסקריפט).
- **הבדיקה האוטומטית של השרת עדיין "PENDING"** אחרי אישור: Deploy ← New deployment ← Web app ← Execute as: **Me**, Who has access: **Anyone** ← Deploy. עדכונים עתידיים ימשיכו להתעדכן אוטומטית.
- **Siri אומרת שהתיעוד נכשל**: אין קליטה, או שהמפתח הוחלף (`rotateKey`). צרו את הקיצורים מחדש בשלב 4.
- **קובץ קיצור נדחה בטלפון**: כאן הייצור האוטומטי לא הצליח. בנו קיצור אחד ידנית: Shortcuts ← + ← Get Contents of URL (POST, JSON עם השדות key, action, id, type, detail, start, user, source) ← Get Dictionary Value `speech` ← Speak Text. ודווחו כדי שנתקן את הקבצים.
- **להחליף מפתח** (למשל אם הוא דלף): בעורך הסקריפט הריצו **rotateKey**, ואז התקינו מחדש את האפליקציה והקיצורים עם הקוד החדש.
