# מדריך התקנה (לבעל החשבון)

כתובות וקודים אישיים לא נכתבים כאן. אותם מקבלים במהלך ההתקנה.

## 1. פעם אחת: הפעלת GitHub Pages
אם האתר לא נפתח: במאגר ב-GitHub, Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **gh-pages**, תיקייה **/ (root)** ← Save.
אחרי דקה האתר חי. אותה כתובת תהיה כתובת האפליקציה.

## 2. אישור השרת (כ-3 דקות, פעם אחת)
1. ב-Google Drive תמצאו שני גיליונות: **BabyLog** (האמיתי) ו-**BabyLog TEST** (לבדיקות אוטומטיות).
2. ב-script.google.com לחצו על הפרויקט **BabyLog** (העורך נפתח מיד; התפריט Extensions קיים רק בתוך הגיליון עצמו).
3. למעלה, בתפריט הפונקציות ליד Run, בחרו **setup** ולחצו **Run**.
4. Google תבקש הרשאה: Review permissions ← בחרו את החשבון ← "Google hasn’t verified this app" ← **Advanced** ← **Go to BabyLog (unsafe)** ← Allow.
   (זה הסקריפט שלכם עצמו, והוא מבקש גישה רק לגיליון הזה.)
5. בחלון ה-Execution log יודפס **קוד התקנה** שמתחיל ב-`BL1.`. העתיקו אותו. זה המפתח הסודי: אל תשלחו אותו בשום מקום ציבורי.
6. אותו דבר ב-**BabyLog TEST** (רק Run על setup ואישור, בלי להעתיק קוד). זה מאפשר לבדיקות האוטומטיות לרוץ.

**חשוב:** הכתובת בתוך הקוד חייבת להסתיים ב-`/exec`. אם הודפסה שורה שמתחילה ב-WARNING, או שהאפליקציה כתבה שהקוד מכיל כתובת `/dev`, זו כתובת בדיקה שעובדת רק בתוך העורך. הפתרון: להריץ שוב **rotateKey** (אחרי שהגרסה העדכנית נפרסה) ולהשתמש בקוד החדש, או להעתיק ב-Deploy ← Manage deployments את ה-Web app URL שמסתיים ב-`/exec` ולהדביק אותו בשדה שהאפליקציה מציגה. אם הקוד נשלח במקום לא מאובטח, גם כאן עדיף **rotateKey**: הוא מבטל את הקוד הישן.

## 3. התקנת האפליקציה בכל טלפון
1. פתחו את כתובת האתר ב-**Safari** (חייב Safari).
2. כפתור השיתוף ← **Add to Home Screen**.
3. פתחו את האפליקציה **מהאייקון במסך הבית**, הדביקו את קוד ההתקנה, והגדירו שמות: הורה 1, הורה 2 ושם התינוק (נשמרים בגיליון הפרטי בלבד). בחרו "מי אני".
4. בטלפון השני אותו קוד. השמות כבר ימולאו, רק בוחרים "מי אני".

## 4. קיצורי Siri (ב-Mac, כ-5 דקות)
לפני כן, בכל טלפון: הגדרות ← Siri: לוודא ש"להאזין ל..." ו"Siri כשהמכשיר נעול" מופעלים, ולראות באיזו **שפה** Siri מוגדרת.

בטרמינל ב-Mac, עם כתובת האתר במקום `SITE`:

```bash
curl -fsSL "SITE/shortcuts/sign.sh" -o /tmp/babylog-sign.sh
BABYLOG_SITE="SITE" bash /tmp/babylog-sign.sh
```

הסקריפט מבקש להדביק את קוד ההתקנה (לא מוצג בזמן ההדבקה), שואל את השרת מה שמות ההורים ומה מין התינוק, ויוצר על שולחן העבודה
תיקייה לכל הורה, ובתוכה שתי תיקיות: **English** ו-**עברית**. כל הורה מקבל רק את התיקייה שמתאימה לשפת Siri בטלפון שלו (Siri מבינה
בכל רגע שפה אחת), ב-AirDrop. בטלפון: לפתוח כל קובץ ← **Add Shortcut**. בהפעלה הראשונה של כל קיצור iOS שואלת אם לאפשר חיבור לשרת:
לבחור **"אפשר תמיד"**. אחר כך למחוק את התיקייה מה-Mac (יש בה את המפתח). לא לשתף את הקיצורים בקישור iCloud או בוואטסאפ.

| מה | עברית ("היי סירי, ...") | English ("Hey Siri, ...") |
|---|---|---|
| הנקה ימין / שמאל | הנקה ימין · תסמני הנקה ימין · הנקה שמאל · תסמני הנקה שמאל | Right feed · Log right feed · Left feed · Log left feed |
| חיתול | חיתול פיפי · חיתול קקי · חיתול מלא | Wet diaper · Poop · Poop diaper · Full diaper |
| שינה | התינוק נרדם · התינוק התעורר (לבת: התינוקת נרדמה · התינוקת התעוררה) | Asleep · Awake |
| ויטמין D | ויטמין די | Vitamin D |
| שאלה | מתי הנקה אחרונה | Last feed |
| שאלה ואז רישום | **יומן תינוק** ← Siri: "מה לרשום?" ← "הנקה ימין" / "פיפי" / "קקי" / "פיפי וקקי" / "נרדם" / "התעורר" / "ויטמין די" | **Baby log** ← "What should I log?" ← "Right feed" ... |

Siri עונה במשפט קצר ("נרשמה הנקה ימין, 14:10. הבאה: שמאל"). כשהקיצור מופעל בהקשה ולא בקול, התשובה מופיעה בשקט בהודעה למעלה.
אם אין קליטה או שהשרת לא ענה: Siri אומרת שלא נשמר (אין תור כמו באפליקציה): לרשום שוב או באפליקציה.

**להוסיף או לשנות ביטוי** (בלי Mac ובלי לחכות לעדכון): ביישום קיצורים, לחיצה ארוכה על קיצור ← **שכפול**, ואז לחיצה ארוכה על העותק ←
**שינוי שם** לביטוי החדש (למשל "הנקה בצד ימין"). השם הוא מה שאומרים ל-Siri, ולכן ביטוי נוסף = עוד עותק בשם אחר. כדי שביטוי יגיע
גם בהתקנות הבאות, לבקש שיתווסף לרשימה ב-`scripts/shortcuts/builder.ts` ולהריץ שוב את הסקריפט.

## 5. הפעלה בלי לפתוח את האפליקציה
- **Back Tap**: הגדרות ← נגישות ← מגע ← Back Tap ← הקשה כפולה/משולשת ← לבחור קיצור (למשל **יומן תינוק**: תפריט בחירה).
- **כפתור הפעולה** (אצל מי שיש): הגדרות ← Action Button ← Shortcut.
- **מרכז הבקרה / מסך הנעילה**: Edit ← Add a Control ← Shortcuts.
- **AirPods / Apple Watch**: אותם ביטויים עובדים גם דרכם.

## 6. בדיקת קבלה (כ-15 דקות)
בכל טלפון: לחיצה על כל כפתור (תופיע הודעת "נשמר" עם ביטול), היסטוריה/עריכה/מחיקה, הוספה בדיעבד, מצב טיסה (נרשם, ומסתנכרן אחרי חזרת הקליטה), מצב לילה, "היי סירי, הנקה ימין" / "Hey Siri, Left feed" לפי שפת Siri בטלפון (גם כשהטלפון נעול: **לבדוק אם נדרש Face ID**), ובאפליקציה הרישום מופיע עם 🎙.
בדקו שהשינוי של הורה אחד מופיע אצל השני תוך דקה.

## 7. שכבת AI (בדיקה)
חברו את Google Drive ל-ChatGPT ול-Gemini ושאלו, למשל:
- כמה פעמים הוא אכל אתמול?
- מה הרווח הממוצע בין ההאכלות הלילה?
- כמה שעות ישן ביממה האחרונה, ומה הרצף הארוך ביותר?
- היו חיתולים עם קקי היום?
- ניתן ויטמין D היום?

אם Gemini לא רואה גיליון ששותף איתכם: הוסיפו את הגיליון ל"ה-Drive שלי" דרך Shortcut.

## אם משהו לא עובד
- **האפליקציה אומרת "המפתח לא תקין"**: Settings ← ניתוק, והתחברו מחדש עם קוד מ-`printInstallCode` (בעורך הסקריפט).
- **הבדיקה האוטומטית של השרת עדיין "PENDING"** אחרי אישור: Deploy ← New deployment ← Web app ← Execute as: **Me**, Who has access: **Anyone** ← Deploy. עדכונים עתידיים ימשיכו להתעדכן אוטומטית.
- **Siri אומרת שהתיעוד נכשל**: אין קליטה, או שהמפתח הוחלף (`rotateKey`). צרו את הקיצורים מחדש בשלב 4.
- **קובץ קיצור נדחה בטלפון**: כאן הייצור האוטומטי לא הצליח. בנו קיצור אחד ידנית: Shortcuts ← + ← Get Contents of URL (POST, JSON עם השדות key, action, id, type, detail, start, user, source, lang = he או en) ← Get Dictionary Value `speech` ← Show Result. ודווחו כדי שנתקן את הקבצים.
- **להחליף מפתח** (למשל אם הוא דלף): בעורך הסקריפט הריצו **rotateKey**, ואז התקינו מחדש את האפליקציה והקיצורים עם הקוד החדש.
